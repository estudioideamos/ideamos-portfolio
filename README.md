# Portfolio Ideamos

Sitio estático para compartir trabajos con clientes. Publicación: https://estudioideamos.github.io/ideamos-portfolio/

## Actualizar proyectos

Editar `projects.js`. Cada proyecto tiene `id`, `name`, `category` (tiendas, corporativos o apps), `sector`, `description`, `image` y `url`. Si no hay sitio público, dejar `url` vacío: se mostrará la vista de diseño. Agregar imágenes a `assets/`.

Las capturas provienen de las publicaciones públicas de los proyectos. El logo, Gilroy y las vistas de Trébol Café, ONER VFX, Raisa Joya y Mirtatulaj provienen de ideamos.com.ar. Las extensiones se presentan con composiciones tipográficas; no se publica su código privado.

## Desarrollo y publicación

No requiere compilación ni dependencias. Servir esta carpeta con un servidor estático. GitHub Pages publica la rama `main` desde la raíz. Verificar filtros, búsqueda, apertura/cierre de proyectos y vistas móvil y escritorio al modificar la galería.
